# Original web examples

## [Fieldwork](fieldwork/)

A complete, dependency-free HTML/CSS/JavaScript design study for a fictional creative studio. It demonstrates editorial hierarchy, original SVG artwork, responsive composition, keyboard-operable navigation, project filtering, native disclosures, and a useful no-script baseline.

Open [fieldwork/index.html](fieldwork/index.html) locally or serve the directory as described in its [README](fieldwork/README.md). There is no build step, framework, external font, analytics, or backend.

Treat the example as a readable implementation reference. Change the art direction, content model, and interactions to fit each real brief instead of producing the same studio page repeatedly.
