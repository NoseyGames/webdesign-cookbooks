A small reading method

Look past the surface.

  1. Read the HTML. Follow the content and landmarks before looking at the finished layout.
  2. Trace the CSS. Identify the spacing, typography, alignment, and responsive decisions that give the page its character.
  3. Exercise the JavaScript. Try every state with a keyboard. Then inspect what stays useful if the script never loads.
  4. Change the brief. Keep the useful behavior and make a new visual direction. Each directory's README explains where to start.
