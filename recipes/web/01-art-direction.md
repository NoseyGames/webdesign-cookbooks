# 01 · Turn references into an original direction

**Use when:** a brief asks for “premium,” “modern,” or “like this website” without explaining the design decisions.

**Inputs:** real audience, one desired action, content inventory, constraints, and two or three references with evidence. **Output:** a short direction sheet before code.

## Method

1. Write the page's job in one sentence: “Help independent founders judge our craft and download a project brief.” Do not invent customer logos, awards, business metrics, or testimonials to fill space.
2. Select references for different reasons: one for composition, one for typography, one for interaction. Record what you actually inspected: text extraction, desktop screenshot, narrow viewport, or interaction. Text extraction cannot establish motion quality or exact visual appearance.
3. Describe each useful relationship rather than naming a trendy effect: “A quiet metadata row lets one oversized headline dominate”; “project artwork occupies more area than its caption.”
4. Define a direction with four decisions: mood, density, type contrast, and image language. Example: tactile editorial / generous / neutral sans plus italic serif / original geometric prints.
5. State what the page must avoid for this particular brief: perhaps boxed sections everywhere, unsupported metrics, or animation that delays the work. These are project choices, not universal bans.
6. Sketch the full page in words. Give each section a job: proposition → selected proof → working approach → next action. Remove sections that repeat an earlier job.
7. Make one coherent visual experiment. Compare it with the direction sheet before polishing details.

## Concrete direction sheet

```text
Audience: founders choosing a small design studio
Action: download a project brief
Promise: considered identity and useful digital experiences
Composition: strong left-aligned headline; one oversized geometric print
Palette: warm paper, near-black ink, one oxide red accent
Type: system sans for information; italic serif for one expressive phrase
Rhythm: large opening → paired work → compact method → strong closing
Signature: crop and overlap original circular geometry; keep text clear
Constraints: readable at 320 CSS px; zero required external assets
Evidence: fictional project descriptions labelled as concept work
```

## Acceptance checks

- At a glance, a reader can identify what the organization does and the next action.
- There is one primary focal point per section. Three equally loud elements need another composition pass.
- The system survives removal of all decorative artwork.
- The result does not reuse reference logos, copy, proprietary artwork, or page composition wholesale.
- Every claimed observation has a source and an inspection method. Inferences are labelled.

**Common repair:** if a page feels generic, do not add more gradients. Revisit content specificity, type scale, image treatment, and section rhythm.

**Try it:** change the [Fieldwork example](../../examples/web/fieldwork/) into a science journal without changing its HTML first. Notice where its editorial system transfers and where the content requires a different structure.

The direction method is an editorial heuristic, not a web standard. Semantic structure and adaptable presentation still matter; see [W3C's page structure tutorial](https://www.w3.org/WAI/tutorials/page-structure/).
