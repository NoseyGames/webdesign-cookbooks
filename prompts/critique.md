# Critique and improve

Inspect the implementation and its actual output. Use evals/rubric.md and the brief. Return the three most consequential defects, each with visible or reproducible evidence, user impact, and a concrete correction. Distinguish functional defects from taste preferences. If screenshots, keyboard tests, runtime output, or performance evidence are missing, identify the gap instead of inferring a pass.

Then implement authorized fixes, repeat the checks affected by those fixes, and explain the result. Do not add visual effects simply to increase novelty. A quiet, content-led design can be the right answer.
