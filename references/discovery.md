## Make discovery useful

For each new reference, capture one transferable design relationship, its evidence, and one implementation constraint. Avoid collecting fifty thumbnails without learning anything reproducible.

Use this small record:

```text
Primary URL:
Inspected date and viewport:
Evidence method: text / screenshot / interaction / measured performance
Observed composition:
Observed typography and density:
Observed interaction and alternate state:
Hypothesis worth trying in an original design:
Risk or constraint to investigate:
What was not verified:
```

Choose a reference because it fits the current brief. A spectacular immersive site is not automatically the right model for a documentation page, booking flow, or low-bandwidth audience. Keep links and original analysis; do not import another studio's source, screenshots, fonts, video, or artwork into a training dataset without appropriate rights.
